# Hamdel-PDF-OCR-Pro
برنامه دسکتاپ ویندوزی فوق‌العاده پیشرفته تبدیل PDF به متن با OCR کامل آفلاین، پشتیبانی از فایل‌های اسکن‌شده، تبدیل به TXT/HTML و فرمت‌های دیگر، موتور صوتی طبیعی آفلاین، دسترسی‌پذیری کامل برای نابینایان (سازگار با NVDA)، کتابخانه فایل‌ها، میانبرهای کیبورد فراوان. ساخته‌شده توسط گروه تکنولوژی همدل - آکادمی همدل
