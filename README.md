# Hamdel PDF OCR Pro

برنامه دسکتاپ ویندوزی برای تبدیل فایل‌های PDF به متن با دقت بالا.

این ابزار مخصوص کسانی ساخته شده که با فایل‌های اسکن‌شده یا تصویری سروکار دارند و می‌خواهند متن را استخراج کنند. کاملاً آفلاین کار می‌کند و برای کاربران نابینا هم بهینه شده است.

**ساخته‌شده توسط گروه تکنولوژی همدل**  
کانال تلگرام: [آکادمی همدل](https://t.me/Akademi_hamdel)

---

## ویژگی‌های اصلی

- استخراج متن از PDFهای متنی و اسکن‌شده (OCR)
- پشتیبانی از زبان‌های پارسی، انگلیسی و عربی
- خروجی در قالب TXT، HTML و Markdown
- موتور تبدیل متن به گفتار آفلاین با صدای طبیعی
- رابط کاربری دو زبانه (فارسی / انگلیسی)
- سازگاری کامل با صفحه‌خوان NVDA و کنترل کامل با کیبورد
- کتابخانه شخصی برای نگهداری فایل‌های تبدیل‌شده
- نصب‌کننده گرافیکی با جادوگر نصب (Setup Wizard)
- میانبرهای کیبورد متعدد
- کاملاً آفلاین؛ بعد از نصب هیچ وابستگی خارجی نیاز نیست

## نصب برای کاربر نهایی

کافی است آخرین نسخه را از بخش [Releases](https://github.com/babayyamyrhsyn33-code/Hamdel-PDF-OCR-Pro/releases) دانلود کنید و فایل نصب را اجرا کنید.

جادوگر نصب خودش همه چیز را از شما می‌پرسد:
- انتخاب زبان رابط
- مسیر نصب
- ایجاد میانبر دسکتاپ و منوی استارت

بعد از نصب، برنامه آماده استفاده است و نیازی به نصب هیچ کتابخانه یا ابزار اضافی نیست.

## ساخت از سورس (برای توسعه‌دهندگان)

### پیش‌نیازها
- پایتون ۳.۱۰ یا بالاتر
- Tesseract OCR (با زبان‌های fas و eng)
- Poppler

```bash
git clone https://github.com/babayyamyrhsyn33-code/Hamdel-PDF-OCR-Pro.git
cd Hamdel-PDF-OCR-Pro
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

جزئیات بیشتر ساخت در فایل `docs/BUILD.md` آمده است.
